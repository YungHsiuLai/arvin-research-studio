# Arvin Research Studio

量化行銷與 B2B 研究的公開資料集目錄。

[開啟 Research Studio](https://yunghsiulai.github.io/arvin-research-studio/)

[查看更新紀錄](CHANGELOG.md)

本儲存庫只存放經審查的靜態網站：資料集摘要、原始欄位定義、逐欄範例、測量補充、變數用途、文獻案例、全域方法庫、個人講義 HTML 與公開分析摘要，支援繁體中文及英文。

現行六個資料集共 42 張表、505 欄，全部提供經審閱的範例；真實值直接顯示，只有虛構或經替換的範例加註說明。文字節錄保留省略號，不同欄的值不構成一筆紀錄。資料型別首次出現時附白話括號說明與格式例，隨選表、篩選、收合及語言更新。

總首頁保留標題、短標語、收錄數量與所有資料集／研究設計與方法兩個入口，不放介紹段落。資料集、方法與研究設計案例數依目錄自動計算；這些是內容數量，不代表使用者已熟練。原本的資料集列表保留為下一層頁面。頁首選單旁固定顯示 Home／首頁，保留語言並直接返回總首頁，手機可換行。

RoyaltyStat、FactSet Revere、InfraClear 與 Supply Chain 共用識別資訊、交易特徵、治理、績效及其他五個邏輯分類，提供逐欄雙語理由；每個表欄位只歸一類，各類加總等於所有欄位，跨表同名欄位分別辨認。未知測量與通用抽取值先放其他，沒有對應測量的類別保留 0；契約付款條件不等同已實現績效。Supply Chain 只顯示 seglink 主表的 14 欄，已包含於主表的子集留在內部歸檔。

左側研究工作台在所有頁面只保留所有資料集與研究設計與方法兩個主題。資料集頁上方可直接切換欄位、分析與文獻案例等子頁，手機支援橫向捲動；方法頁保留自己的方法目錄與研究設計流程，不混入資料集導覽。只有多個 Schema 的資料集顯示分組篩選，單一分組時隱藏重複選項。

左側不再顯示資料集切換，統一使用右上角選單。字典搜尋列不顯示結果欄位數，也沒有索引標題數字徽章；所有欄位及各分類保留數量，方便核對加總。

欄位第二項說明標為「AI查核／AI verification」。RoyaltyStat 識別欄位補充可串接的量化財務資料來源與匹配限制；排他性欄位以白話說明非專屬、專屬與 sole licence，區分一般用語及資料商碼表，未確認的碼值仍保留未知。

已逐項檢視現行 505 欄的類別與範圍語意，補充可確認的標籤意思、端點、順序與特殊值區別；未取得正式碼表、門檻、版本或單位規則時明示缺口，不宣稱全部定義已核實。「所有欄位」前四個短項目依序顯示時間、樣本規模、檔案大小，以及潛在 IV、可測量 DV 與可串接外部 DV 的識別欄位；用途附條件，不替使用者選題。

潛在 IV／DV 摘要分成 IV、DV、External DVs／外部 DV 三個子項，只有子項標籤加粗，內容依語言選擇分行顯示。

搜尋依介面標示的明確欄位清單執行：EDGAR 只查類型代碼，方法庫不查內部 metadata。字典可選全部（預設）、只查欄位名稱，或查欄名以外的表名、型別、定義、AI查核與變數用途；切換範圍保留關鍵字、選表與其他篩選。已撰寫的中英文內容均可查找，結果不隨顯示語言改變；字典顯示欄位及 CSV 依同一份交集結果輸出。

SEC EDGAR 為獨立資料集，提供已驗證的 EX-10 技術授權／合作合約及 EX-11 文件、共用文件清單、官方代碼分類與容量範圍。EX-11／EX-12 的附件要求於 2018-11-05 取消，編號保留空缺；已取得文件的申報期間另列，不能以法規日期代替全類別資料終點。達重大契約申報條件的技術授權通常可在 EX-10 找到；部分下載及官方 ZIP 大小不代表完整 EDGAR 檔案庫。

EDGAR 的資料表與欄位後另有 Key content／關鍵內容分頁，呈現兩份 EX-10 合約的原文短句、條款位置、雙語說明與解讀界線。合約可收合，原文引句在兩種介面保留英文，完整文件連回 SEC；字典的範例卡片可直接進入對應內容。範例申報期間保留在卡片上方，用途與期間說明移到卡片之後。這些閱讀註記不新增資料欄位或分析紀錄，也不把合約約定或未公開內容當作已實現績效；一般建置只讀經審閱 metadata。

[Research design & methods](https://yunghsiulai.github.io/arvin-research-studio/#methods) 以方法為索引，文章各自保留設定與策略案例。各資料集的 Data analysis 收錄回答經驗問題的敘述統計、分布、趨勢、關聯或模型結果，不要求因果識別或正式論文；完整成果留在本機。涵蓋、容量與品質等資料準備查核不列入分析，其內部紀錄不公開。目前尚無已登錄分析。

研究設計流程圖依實際方框邊界繪製箭頭，拉長節點間距；視窗、側欄或語言改變時重新對齊。設計頁與完整講義共用，手機可在圖內左右捲動。

Farronato–Zervas 設計區塊底部提供完整期刊引用與 DOI，兩種介面保留原文篇名。出版商核對僅確認書目；方法與結果仍依個人講義轉述，不代表已獨立重現或驗證。

側欄依選取語言顯示學術、非商業內部參考與禁止未授權存取、轉載、使用的精簡聲明。HTML 原始碼另含不外顯的外部 AI 存取／使用禁令；這是使用政策，不是登入驗證或技術封鎖，原始碼仍可被查看。

方法附精簡白話情境；公式使用可反白的 MathML，並提供 Copy LaTeX。資料表的筆數與範圍會區分精確查詢、估計及仍未確認的資訊；伺服器儲存大小不代表本機下載檔案大小。

網站由私有研究工作區的公開版本建置工具產生，只載入已審閱的逐欄範例，不包含完整觀察列、個人或公司擷取檔、查詢憑證、私人練習紀錄或機器路徑。

每次公開更新都應先維護來源工作區的 README 與 CHANGELOG，再重建並同步本機與公開版本；此處的 HTML 為生成結果，CHANGELOG 與來源工作區共用同一份經審查的公開紀錄，避免兩份更新歷史分歧。

完成可獨立驗證的小階段就更新網站並確認部署，不等待長期資料蒐集或整批分析完成。每次以來源與公開產物的 Git commit 保存可回復進度，尚未完成的工作不混入當次版本。

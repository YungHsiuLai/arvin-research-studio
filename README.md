# Arvin Research Studio

量化行銷與 B2B 研究的公開資料集目錄。

[開啟 Research Studio](https://yunghsiulai.github.io/arvin-research-studio/)

[查看更新紀錄](CHANGELOG.md)

本儲存庫只存放經審查的靜態網站：資料集摘要、原始欄位定義、測量補充、變數用途、文獻案例、全域方法庫、個人講義 HTML 與公開分析摘要，支援繁體中文及英文。

[Research design & methods](https://yunghsiulai.github.io/arvin-research-studio/#methods) 以方法為索引，文章各自保留設定與策略案例；各資料集的 Data analysis 記錄已執行的分析，完整成果留在本機。

方法附精簡白話情境；公式使用可反白的 MathML，並提供 Copy LaTeX。資料表的筆數與範圍會區分精確查詢、估計及仍未確認的資訊；伺服器儲存大小不代表本機下載檔案大小。

網站由私有研究工作區的公開版本建置工具產生，不包含授權資料的實際觀察列、個人或公司擷取檔、查詢憑證、私人練習紀錄或機器路徑。

每次公開更新都應先維護來源工作區的 README 與 CHANGELOG，再重建並同步本機與公開版本；此處的 HTML 為生成結果，CHANGELOG 與來源工作區共用同一份經審查的公開紀錄，避免兩份更新歷史分歧。
